Products

A product is the sellable item: its name and description, its price and cost, its inventory, shipping attributes, tax rules, brand, and any custom attributes the category defines. Price ultimately lives on a variant — every product has at least one — so a single product can carry many SKUs while sharing one description and image set.

In the TypeScript SDK a product is created together with its required variants (the response is the hydrated product with resolved stock status and priceRange). In the Python SDK, create sets inventory directly on the product via stock_quantity and related fields.

Create a product​

  • TypeScript
  • Python
const tshirt = await client.products.create({
  categoryId: 'category_apparel',
  name: 'Classic T-Shirt',
  description: 'Comfortable cotton t-shirt',
  price: 24.99,
  sku: 'TS-CLASSIC',
  trackInventory: true,
  isActive: true,
  isAlcoholic: false,
  variants: [
    { axisValues: { Size: 'Small', Color: 'Black' }, price: 24.99, isDefault: true, isActive: true },
    { axisValues: { Size: 'Medium', Color: 'Black' }, price: 24.99, isDefault: false, isActive: true },
    { axisValues: { Size: 'Large', Color: 'Black' }, price: 26.99, isDefault: false, isActive: true },
  ],
});

console.log(`Created ${tshirt.name} with ${tshirt.variants.length} variants`);
from wiil.models.business_mgt import CreateBusinessProduct

product = client.products.create(
    CreateBusinessProduct(
        name="Wireless Mouse",
        description="Ergonomic wireless mouse with 6 buttons",
        price=29.99,
        sku="WM-2024-BLK",
        barcode="123456789012",
        category_id="category_accessories",
        brand="TechBrand",
        track_inventory=True,
        stock_quantity=150,
        low_stock_threshold=20,
        weight=0.25,
        is_active=True,
    )
)

Get, list, update, delete​

  • TypeScript
  • Python
const product = await client.products.get('product_123');
const result = await client.products.list();

const updated = await client.products.update({ id: 'product_123', price: 179.99 });

await client.products.delete('product_123');
from wiil.models.business_mgt import UpdateBusinessProduct
from wiil.types import PaginationRequest

by_id = client.products.get("product_123")
by_sku = client.products.get_by_sku("WH-2024-BLK")
results = client.products.list(params=PaginationRequest(page=1, page_size=50), include_deleted=False)

updated = client.products.update(
    UpdateBusinessProduct(id="product_123", price=179.99, stock_quantity=100)
)

client.products.delete("product_123")

The Python SDK looks products up by SKU with get_by_sku; in TypeScript, SKU lookup is a variant operation.

Limits

Both SDKs cap batch creation at 100 products per request.

Variants are required

Every product must have at least one variant — price and per-SKU stock live on the variant. The TypeScript SDK creates variants inline (and exposes a dedicated variants & axes resource); the Python create sets stock_quantity and pricing on the product directly.

Query options​

BusinessProduct queries filter by search, locationId, categoryId, isActive, brand, brandId, trackInventory, priceRange, lowStock, isAlcoholic, and tags, sorted by name, price, createdAt, or displayOrder (asc / desc), with page/pageSize pagination.

tip

Track cost for margin analysis, set reorderPoint and leadTime for replenishment alerts, and mark isAlcoholic so age verification triggers in the order flow.
